- **Topbar navigation fix:** the Pokédex button is now a toggle (opens the pool, shows "← Back" to return to the prior screen), and the step chips (Draft/Loadout/Gauntlet/Battle/Results) are clickable to any already-reached screen. Previously the pool was a dead end.
- **Frontend redesign (new):** adopted the Scarlet/Violet open-design (`rollmons/open_design/index.html`) as the live SPA — a screen-based flow (title → draft → **loadout** → gauntlet → battle → results, + Pokédex/pool). Ported into the 3-file harness structure (`index.html`/`styles.css`/`app.js`), dropped the open-design's offline/demo scaffolding, and **added the loadout screen** (which postdated the open-design) wired to `POST /api/drafts/{id}/loadout`. The Pokémon Showdown replay embed (`replayDoc` + iframe) is unchanged per the constraint that the battle viewport is hard to alter. Single-boss test, drag-reorder ladder, custom-boss add/edit, thin-reroll, skips, damage summary all preserved. Backend untouched; API shapes already matched.
- **Multi-set loadout (new):** each drafted Pokémon offers a choice of sets on a dedicated post-draft "Choose each Pokémon's set" panel (`#loadout-panel` in the main column). Override files may hold multiple export blocks; selectable sets = override sets + active source's sets (Smogon, or randbats fallback). Default is a **non-Mega** set (Mega is opt-in; only one Mega evolves per battle). Endpoints: `POST /api/drafts/{id}/loadout`; loadout locks once a battle/boss rush starts.
- **Megas in the player pool:** `rollmons/sets/<species>.txt` overrides now contribute draftable atoms to the legality matrix (base species typing/gen). 36 Mega sets shipped under `rollmons/sets/`. Override exports are normalized to strip the inert Tera line and guarantee `Level: 100` (`_normalize_override_export`), so authors may omit the level line. Charizard offers Mega X, Mega Y, and a normal set.

- **Bug fixes:** boss-rush damage summary no longer duplicates (normalized per-Pokémon keys + display map); summary renders once (green `#gauntlet-summary`); first boss-rush replay no longer renders blank (panel revealed before iframes are created).

## Open questions / known issues
- **[BUG — fix next session] Redesigned Battle theater replay not showing.** In the new SPA's Battle screen (`#theater`, `renderTheater`/`renderRun` in `app.js`), the first battle's replay can render as a **blank grey frame**, and the **"Waiting for the first battle…" placeholder is not cleared** when the first result arrives (it stays above the first battle card). Root cause likely in `renderRun`: it only clears `#theater` when `results.length===0`, so `renderTheater` appends real cards onto the leftover placeholder; the blank iframe is the hosted-replay player not initializing (same class of issue as the old-UI fix where the container must be laid out before the iframe is created). Reproduces in the live boss rush (e.g. screenshot: "Player vs Ash · Player wins · 20t" card with a grey iframe while the placeholder still shows). Not fixed yet per user's call.
- **`rollmons/bosses_2/` is staged but NOT used.** Future boss teams (Eevee, LC, Cyrus, Maxie, Archie, Giovanni) live there. `boss_loader.py` only reads `rollmons/bosses/`, so these do not appear in the gauntlet until promoted/wired in.
- **Battle can wedge the live web app.** A flaky/hung boss-rush battle can kill the single uvicorn worker and leave a zombie battle worker, making `:8080` unresponsive (observed this session; recovered by restarting `make live`). Hardening idea: run battles in a supervised subprocess with a hard timeout so a stuck battle returns an error instead of taking down the server.
- **Battle-runner flakiness:** standalone `run_battle` invocations intermittently time out or lose to Showdown inactivity (player never moves). The web-UI boss rush is the reliable path. Weak/Smeargle-style teams can crash the gen9-no-Tera engine search.
- Legendary down-weighting is "leaky" — it only affects appearance in cells with >5 candidates and the suggested pick. User confirmed current behavior is fine; revisit only if legendaries should be genuinely rarer.

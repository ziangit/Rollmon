## Open questions / known issues
- **[BUG — fix next session] Redesigned Battle theater replay not showing.** In the new SPA's Battle screen (`#theater`, `renderTheater`/`renderRun` in `app.js`), the first battle's replay can render as a **blank grey frame**, and the **"Waiting for the first battle…" placeholder is not cleared** when the first result arrives (it stays above the first battle card). Root cause likely in `renderRun`: it only clears `#theater` when `results.length===0`, so `renderTheater` appends real cards onto the leftover placeholder; the blank iframe is the hosted-replay player not initializing (same class of issue as the old-UI fix where the container must be laid out before the iframe is created). Reproduces in the live boss rush (e.g. screenshot: "Player vs Ash · Player wins · 20t" card with a grey iframe while the placeholder still shows). Not fixed yet per user's call.
- **`rollmons/bosses_2/` is staged but NOT used.** Future boss teams (Eevee, LC, Cyrus, Maxie, Archie, Giovanni) live there. `boss_loader.py` only reads `rollmons/bosses/`, so these do not appear in the gauntlet until promoted/wired in.
- **Battle can wedge the live web app.** A flaky/hung campaign/boss-rush battle can kill the single uvicorn worker and leave a zombie battle worker, making the web port unresponsive (observed; recovered by restarting `make live`). Hardening idea: run battles in a supervised subprocess with a hard timeout so a stuck battle returns an error instead of taking down the server.
- **Battle-runner flakiness:** standalone `run_battle` invocations intermittently time out or lose to Showdown inactivity (player never moves). The web-UI boss rush is the reliable path. Weak/Smeargle-style teams can crash the gen9-no-Tera engine search.
- Legendary down-weighting is "leaky" — it only affects appearance in cells with >5 candidates and the suggested pick. User confirmed current behavior is fine; revisit only if legendaries should be genuinely rarer.
- AGENTS.md "Locked Decisions" / roadmap predate player-pool Megas; AGENTS.md body has been updated but re-read before relying on older phrasing.
- Roadmap: the fixed ten-battle campaign is now built (tiered `rollmons/pool/`); remaining — deepen thin tiers, difficulty-tune per tier (team strength × boss AI search time), and consider StS-style per-act boss/elite choice.

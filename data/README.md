# data

`pokedex.json` and `moves.json` are generated from Pokémon Showdown's data
(MIT) and were carried over from the v1 repo (where foul-play's update script
produced them). The reference Python layer reads them for the legality matrix
and existence-only validation. The browser port replaces them with `@pkmn/dex`.

`tiers.json` is generated by `web/scripts/tiers.ts` from `@pkmn/sim`'s format data
(MIT): each species' Showdown tier in the latest generation where it had one.
The leaderboard's team handicap reads it (`web/game/score.ts`). Regenerate
after bumping `@pkmn/sim`.

`species-names.json` is generated by `web/scripts/species-names.ts` from PokeAPI's
`pokemon_species_names.csv` (BSD-3-Clause; the names are Nintendo's): Simplified
Chinese and Japanese species names by National Dex number, for the page's
language switch. Formes keep an English suffix.
